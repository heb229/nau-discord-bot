Discord:
1. Go to https://discord.com/developers/applications
2. Create a new application
3. On the left navigation, click "Bot"
4. Find "Token", then click reset token
5. Follow though and then copy the token
6. Save the token


Code:
1. Fork the project
2. Create a venv, installing requirements.txt
    a. pip install -r requirements.txt
3. Create a .env
    a. add in DISCORD_TOKEN=discord_token
    b. discord_token should be the Token saved prior when creating the bot in Discord Developer.
